Este código e um quiz que gera perguntas baseadas no tópico escolhido, ideal para conhecer ou estudar algum assunto, ele utiliza Inteligência Artificial para gerar as perguntas através da API do Gemini, se desejar usar esse cógido é necessário obter a sua Chave GEMINI_API_KEY e criar um arquivo .env com sua chave no mesmo diretorio do arquivo do código na sua máquina. 

exemplo no arquivo .env deve contera a sguinte linha 

GEMINI_API_KEY="SUA CHAVE DE API VAI AQUI DENTRO DAS ÁSPAS"
